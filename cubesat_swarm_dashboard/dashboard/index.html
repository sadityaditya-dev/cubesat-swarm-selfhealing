END-TO-END PROCESS

Mission workflow status

END-TO-END PROCESS

Simulation subsystem architecture

Live state flows through the same model
01 · SPACECRAFT STATE

Satellite model

State vector, current role, installed/effective capabilities, health, energy proxy, Δv and thrust authority.

02 · PHYSICS & EVENTS

Simulation engine

RK4 integration of planar HCW dynamics, scheduled events, bounded controls and telemetry snapshots.

03 · HEALTH & LINKS

Heartbeat / failure monitor

Sequence tracking, packet loss, timeout suspicions, temporary link isolation and confirmation of model-injected bus faults.

04 · DECISION

Role manager

Exact candidate enumeration with capability feasibility, target distance, switch cost, energy, Δv, link quality and sensor contribution.

05 · CONTROL

Formation controller

Role target positions, bounded feedback acceleration, maneuver budget consumption and heuristic close-approach response.

06 · MISSION VALUE

Coverage manager

Current footprint union, grid cells, observation points, uncovered gaps, and each sensor's unique coverage contribution.

07 · RECOVERY

Recovery verifier

Checks failed-role exclusion, survivor count, critical role feasibility, connectivity, separation, coverage target and formation convergence.

08 · INTERFACE

Dashboard API

Start/pause/reset, speed, fault scheduling/injection, live telemetry and JSON/CSV exports are connected to this state.

The configured mean motion n defines the circular reference orbit. The integrator uses RK4. Sensor footprints and network links are software abstractions in the LVLH frame; the model does not represent Earth-ground geography or certify spacecraft safety.
